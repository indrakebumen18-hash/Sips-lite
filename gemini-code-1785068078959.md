# SIPS Lite - Sistem Informasi Pembinaan Santri (v1.0)

Aplikasi pencatatan pelanggaran santri berbasis Mobile Web App (PWA). Aplikasi ini dirancang 100% berjalan offline tanpa memerlukan server atau database eksternal. Semua data disimpan secara lokal menggunakan `LocalStorage` pada perangkat Anda.

## Fitur Utama
1. **Master Data Lengkap:** Kelas, Santri, dan Kategori Pelanggaran.
2. **Catat Pelanggaran:** Form input dinamis otomatis menghubungkan data.
3. **Dashboard Realtime & Statistik:** Pantau jumlah kelas, santri, pelanggaran harian, serta santri dengan poin tertinggi (tanpa refresh).
4. **Riwayat & Filter:** Telusuri kejadian berdasarkan tanggal, kelas, atau nama santri.
5. **Mode Gelap (Dark Mode):** Otomatis menyesuaikan perangkat (sistem) atau dikontrol manual.
6. **Progressive Web App (PWA):** Dapat diinstall di layar utama Android (Home Screen) sebagai aplikasi native-like.
7. **Backup & Restore:** Ekspor seluruh data ke dalam file `.json` dan pulihkan ke perangkat mana saja.
8. **Vanilla Stack:** Sangat ringan dan responsif, dibangun tanpa Framework (Murni HTML, CSS, JS).
